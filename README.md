# Basic-Fundamental
No.	Istilah	Penjelasan Singkat
1.	Algoritma	Urutan langkah-langkah logis untuk menyelesaikan suatu masalah atau tugas.
2.	Bahasa Pemrograman	Bahasa yang digunakan untuk menulis instruksi agar komputer dapat menjalankan program (misalnya Java, Python, C++).
3.	Variabel	Tempat menyimpan data yang nilainya dapat berubah selama program berjalan.
4.	Konstanta	Nilai yang tetap dan tidak dapat diubah setelah dideklarasikan.
5.	Tipe Data	Menentukan jenis data yang dapat disimpan, seperti int, float, char, atau String.
6.	Percabangan	Struktur pengambilan keputusan berdasarkan kondisi tertentu, misalnya if, else, atau switch.
7.	Perulangan	Struktur yang digunakan untuk mengulang suatu proses, seperti for, while, dan do-while.
8.	Package	Kumpulan kelas atau modul yang disusun dalam satu kelompok agar kode lebih rapi dan mudah dikelola.
9.	Enkapsulasi	Konsep OOP untuk menyembunyikan data dan mengatur aksesnya melalui metode tertentu.
10.	Inheritance	Konsep OOP yang memungkinkan sebuah kelas mewarisi atribut dan metode dari kelas lain.
11.	Polimorfisme	Kemampuan suatu metode atau objek memiliki banyak bentuk atau perilaku yang berbeda sesuai konteks.
12.	Interface	Kumpulan metode tanpa implementasi yang harus diterapkan oleh kelas yang menggunakannya.
13.	Error Handling	Teknik untuk menangani kesalahan (error) saat program berjalan agar tidak langsung berhenti, misalnya menggunakan try-catch.
14.	Debugging	Proses mencari, menganalisis, dan memperbaiki kesalahan (bug) dalam program.
